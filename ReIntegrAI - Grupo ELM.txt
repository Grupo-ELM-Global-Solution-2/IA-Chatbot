O projeto consiste em uma API REST desenvolvida em Flask que serve dois modelos de Machine Learning treinados para personalizar a experiência do usuário na plataforma ReIntegrAI:

1. MODELO DE CLASSIFICAÇÃO (RandomForest):
   - Objetivo: Recomendar a trilha de tecnologia ideal (ex: Data Science, Cybersecurity) baseada no perfil do aluno (Lógica, Inglês, Área de Origem).
   - Arquivo do modelo: modelo_recomendacao_area.joblib

2. MODELO DE REGRESSÃO (LinearRegression):
   - Objetivo: Estimar o tempo de conclusão da trilha (em semanas) considerando a disponibilidade de horas e o nível de conhecimento prévio.
   - Arquivo do modelo: modelo_estimativa_tempo.joblib



1. Instale as dependências:
   pip install pandas scikit-learn flask joblib

2. Execute a API:
   python app.py

3. A API estará disponível em: http://127.0.0.1:5000/predict (Método POST)
